# Brand assets

## `jsp-logo.png`

The official ЈСП Скопје / NQP Shkup lockup — the city crest with the
Macedonian and Albanian wordmarks.

- **Source:** `https://skopjebus.mk/wp-content/uploads/2024/10/JSP-LOGO-RED-NEW_002.png`
- **Retrieved:** 2026-08-19
- **Size:** 900 × 240, PNG with alpha

### Before going live

- **Ask JSP for the master asset.** This file was taken from their public
  website, which is fine for building against but is a 900px raster. A vector
  (SVG/EPS) would render sharply at any size and on high-DPI screens, and is
  what an organisation normally hands over.
- **Confirm permission in writing.** The app is being built for JSP, so using
  their mark is expected — but get that on the record before deployment, along
  with any brand guidelines they have.

### Rules of use

The mark is used unmodified: not recoloured, not stretched, not cropped, and
not rebuilt from parts. It is red on a transparent ground, so it always needs a
light backing — hence the paper plate it sits on in `BrandPanel.tsx`. Do not
place it directly on the red livery panel.
